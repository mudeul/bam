## 📚 전체 보기
```dataview
TABLE WITHOUT ID
  분류 AS 분류,
  file.link AS 제목,
  저자 AS 저자
WHERE startswith(file.path, "WIND/07. 책갈피/") AND file.name != this.file.name
SORT file.mtime DESC
```
